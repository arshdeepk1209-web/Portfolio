# Arshdeep Kaur — AI & ML Graduate Portfolio (PWA)

A lightweight, offline-ready Progressive Web App (PWA) portfolio built with React, Vite, and Tailwind CSS. Hosted for free on GitHub Pages with zero server fees.

## 🚀 How to Publish to your GitHub Repository

Your GitHub repository is ready at: `https://github.com/arshdeepk1209-web/Portfolio`

Follow either **Option A (Terminal / Command Prompt)** or **Option B (GitHub Desktop / Web)** below:

---

### Option A: Using Command Prompt / Terminal (Recommended - 1 Minute)

Open Command Prompt, PowerShell, or Terminal in your project folder and run:

```bash
git init
git add .
git commit -m "Deploy Arshdeep Kaur Portfolio PWA"
git branch -M main
git remote add origin https://github.com/arshdeepk1209-web/Portfolio.git
git push -u origin main
```

---

### Option B: Using GitHub Desktop

1. Open **GitHub Desktop**.
2. Click **File** → **Add Local Repository**, and select this folder.
3. Click **Publish repository** to `arshdeepk1209-web/Portfolio`.

---

## 🌐 Enable GitHub Pages (Free Hosting)

Once your code is pushed:

1. Go to your repository on GitHub: **`https://github.com/arshdeepk1209-web/Portfolio`**
2. Click on **Settings** (top right tab with the gear icon).
3. On the left sidebar, click **Pages** (under the "Code and automation" section).
4. Under **Build and deployment**:
   - In the **Source** dropdown, select **GitHub Actions**.
5. That's it! The pre-configured `.github/workflows/deploy.yml` will automatically build and publish your site in less than 60 seconds.
6. Your live portfolio URL will be:
   **`https://arshdeepk1209-web.github.io/Portfolio/`**

---

## ✨ Features Included

- ⚡ **100% Offline Viewing**: Cached with Service Worker and Workbox.
- 📱 **Installable PWA**: Can be installed to desktop or mobile home screens as a native standalone app.
- 📄 **1-Click PDF Resume**: Recruiters can download an ATS-compliant PDF resume (`Arshdeep_Kaur_Resume.pdf`) directly.
- 👁️ **Interactive Project Simulators**:
  - **VAAB (Visual AI Assistant for the Blind)**: Vision pipeline & multi-language TTS speech playback.
  - **AI Resume Generator**: Real-time ATS role tailoring engine.
  - **Smart Route AI**: Predictive congestion bypass telemetry comparison.
- 🌓 **Dark / Light Mode Toggle**: Smooth theme switching with local storage persistence.
- 🖼️ **Interactive Profile Photo**: Vector illustration based on your uploaded headshot with interactive photo upload/replacement.
